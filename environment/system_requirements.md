# System requirements

- Python 3.11 or later
- R 4.3 or later
- PLINK 1.9/2.0 for LD operations
- LDSC for genetic-correlation analyses
- LibreOffice only when regenerating rendered DOCX/PDF previews

Exact versions should be captured with `python --version`, `pip freeze`, and `Rscript -e "sessionInfo()"` when rerunning analyses.
